# Dotfiles

Personal configuration files for macOS and Linux.

## Contents

- Shell and Git settings in the repository root
- Desktop, terminal, and application settings in `.config/`
- Shared agent skills in `.agents/skills/`
- Tool-specific settings for Claude, Codex, Orca, and Pi

Symlink the files you need into their expected locations in your home directory. Keep the directory structure intact so shared skill links continue to work.
